## 3. What to capture

Write captures to `.agent-logs/` in the repo root. These are committed and ship with
your repo, publicly, so treat them as part of the submission.

**We want the prompt and the final response. Nothing in between.**

Not the thinking. Not the tool calls. Not the intermediate steps, the file reads, the

back at the end of that turn.

Capture, per turn:

### Compression Instructions (Target < 2 MB per clip)

To ensure rapid loading and smooth playback on static hosting, compress the 720p clips using **FFmpeg** (or any web compressor like Handbrake):

```bash
# 720p H.264, muted (no audio track), 24 FPS, CRF 26 (~800KB - 1.5MB each):
ffmpeg -i input.mp4 -an -vcodec libx264 -crf 26 -preset slow -r 24 -movflags +faststart output.mp4
```

* `-an`: Strips audio tracks (reduces file size by ~20% and ensures instant browser autoplay compliance).
* `-crf 26`: Optimizes visual clarity while reducing file size below 1.5 MB.
* `-movflags +faststart`: Places MP4 moov atom at the front of the file for instant streaming without waiting for full download.
